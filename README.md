# Запуск Telegram-бота

1. Откройте BotFather в Telegram. Перевыпустите токен вашего бота командой /revoke: старый токен был записан открыто в исходнике.
2. Дважды нажмите START_BOT.cmd.
3. Вставьте новый токен в окно и нажмите Enter. Символы при вводе не отображаются — это нормально. Токен не сохраняется в файлах.
4. Откройте своего бота и отправьте /start.

Нужен Python 3.10 или новее. Сторонние библиотеки не нужны. Сайта и Flask здесь нет.
Бот работает, пока это окно открыто, компьютер включён и есть интернет. Остановить: Ctrl+C. Для круглосуточной работы разместите этот же скрипт на постоянно работающем сервере; Vercel для постоянного polling-процесса не подходит.

Для групп: добавьте бота администратором с правами удалять сообщения и блокировать участников. При необходимости отключите Group Privacy через BotFather (/setprivacy), затем добавьте бота в группу заново. Не запускайте одновременно старый и новый скрипт с одним токеном.

Команды: /start, /help, /status, /paysupport. Покупка PRO — кнопка в /start, 100 Telegram Stars на 30 дней. Добавлена обработка pre_checkout_query и проверка подтверждённого платежа; повторный номер оплаты не выдаёт подписку второй раз. Повторная покупка продлевает срок. Владелец: Telegram ID 5224030424, задаётся в bot.py как OWNER_ID. /grant ID и /revoke ID — только владельцу. /ban, /mute 30m, /unmute — ответом на сообщение, только PRO-администратору.

База сохраняется рядом со скриптом в bot_database.json. Не удаляйте её: в ней подписки, предупреждения и номера платежей. Скопируйте старую krolikguard_beta_db.json под именем bot_database.json до первого запуска, если хотите перенести прежние подписки.

Сохранены особенности исходника: чёрный список, муты и предупреждения общие для всех групп бота; PRO-пользователи освобождены от автоматического фильтра. Автомодерация проверяет текстовые сообщения. Это фильтр чата, а не детектор игровых читов.

Проверены синтаксис и обработка платежных событий на имитации Telegram API. Реальная оплата и запуск с новым токеном требуют вашей проверки в Telegram.
